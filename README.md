# Frame Linter — плагин для Figma

Проверяет макеты и помогает их причёсывать:

- **Проверка** — имена слоёв, токены (цвета, радиусы, отступы, стили текста), компоненты, лишние обёртки, скрытые и пустые слои, дубли. Многие замечания исправляются в один клик, в том числе сразу у всех похожих слоёв.
- **Навигация** — собирает блок ссылок на фреймы ряда и кнопки «Вернуться к навигации», проверяет расстояния между блоками и рядами.
- **Правописание** — проверяет тексты в выделенных фреймах (русский и английский, свой словарь).
- **Инструменты** — массовая замена компонентов и размножение фрейма по данным из таблицы.

Интерфейс поддерживает светлую и тёмную тему Figma.

## Установка

Нужен **десктопный Figma** (в браузере плагины из файла не подключаются).

1. Откройте страницу [Releases](../../releases/latest) и скачайте `frame-linter-vX.Y.Z.zip`.
2. Распакуйте архив в постоянное место (например, `~/Documents/figma-plugins/`). Папку потом не удаляйте и не переносите: Figma читает плагин оттуда.
3. В Figma откройте любой файл: **Plugins → Development → Import plugin from manifest…**
4. Выберите файл `manifest.json` из распакованной папки.
5. Запуск: **Plugins → Development → Frame Linter**.

Как пользоваться: выделите фреймы на холсте и нажмите «Проверить фрейм» (или «Проверить всю страницу», если ничего не выделено). Раздел «Навигация» и «Правописание» работают только с выделением.

## Обновление

Когда выходит новая версия, в шапке плагина появляется синяя кнопка **«Доступна версия X.Y.Z»**. Нажмите её: откроется страница загрузки.

1. Скачайте новый zip.
2. Распакуйте поверх старой папки (замените файлы `manifest.json`, `code.js`, `ui.html`).
3. Закройте плагин и запустите снова: **Plugins → Development → Frame Linter**. Повторно импортировать manifest не нужно, если папка осталась на месте.

Настройки хранятся в Figma и после обновления сохраняются.

Подсказка об обновлении читает файл `version.json` из этого репозитория, больше ничего плагин не скачивает и в сеть не отправляет.

## Если что-то не работает

- **Плагина нет в Plugins → Development** — повторите шаги 3–4, папка с `manifest.json` должна лежать на диске.
- **Плагин не открывается после обновления** — проверьте, что в папке есть все три файла: `manifest.json`, `code.js`, `ui.html`.
- **Не исправляется замечание у слоя внутри инстанса** — это ожидаемо: плагин предлагает открыть главный компонент и поправить там.

## Для разработки

```
code.js        логика в Figma (проверки, правки, навигация)
ui.html        интерфейс (стили, скрипты, встроенный словарь правописания)
manifest.json  манифест плагина
version.json   актуальная версия: её читают установленные плагины
tools/         сборка словарей, подъём версии, упаковка zip
```

Выпуск новой версии:

```sh
node tools/bump.mjs 1.1.0 "что нового"   # меняет PLUGIN_VERSION в code.js и version.json
git commit -am "v1.1.0" && git tag v1.1.0 && git push --follow-tags
node tools/pack.mjs                       # dist/frame-linter-v1.1.0.zip
# GitHub → Releases → Draft a new release: тег v1.1.0, приложить zip
```

Кнопка «Доступна версия» появляется у коллег, как только в ветке `main` лежит `version.json` с версией новее установленной, поэтому выкладывайте релиз с zip до или одновременно с пушем.

Словари правописания пересобираются командой `cd tools && npm install && node build-spell.mjs`.
